# MindSpace — Student Wellness Web App 🌿

MindSpace is a student-focused frontend web application designed to help students organize academic tasks, reflect on their mood, and practice simple wellbeing exercises.

## Features

- **Study Rescue:** Add tasks, set deadlines, prioritize assignments, and track progress.
- **Mood Check-ins:** Record moods and view recent reflections.
- **Supportive Chat:** Predefined supportive responses and practical suggestions.
- **Calm Corner:** Guided breathing and the 5–4–3–2–1 grounding exercise.
- **Wellbeing Journal:** Record personal reflections and review recent check-ins.
- **Responsive UI:** Layouts adapted for desktop, tablet, and mobile screens.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

1. Clone or download the repository.
2. Open `index.html` in your browser.

No backend or package installation is required for the current prototype.

## Current Limitations

- Chat replies are predefined, not generated by a live AI model.
- Tasks and reflections are held in page memory and reset when the page reloads.
- This is a wellbeing prototype, not a medical or diagnostic tool.

## Project Goal

Created for a frontend competition to explore how interactive web design can support student organization and wellbeing.
